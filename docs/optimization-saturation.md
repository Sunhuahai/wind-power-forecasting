# 饱和评估与已封路线清单

更新：2026-11-14。严格协议（训练只用 2012，验证集只做选择/早停/权重，测试集只评分）。

当前最优：**0.156009848**（9 个成功节点，相对原 C 基线 0.170454204 降低 **8.47%**）。测试集累计使用 11 次。

## 结论

这条链在现有信息源上**已接近饱和**。最近 5 轮的效应量都在 **1e-4 量级或更低**，而七日块配对区间的半宽约 **2e-4**；也就是说，即使方向真的为正，也普遍跨零。按"验证集区间上界 ≤ −0.0002 才允许开测试集"的门槛，这些改动**在机制层面就过不了门**。

## 为什么"换表征/换超参"这条路走不通：余量测算

以站点嵌入为例，把嵌入能做的事情放到上限估：

- 现行最优在测试集上的**分站偏差**（描述性统计）为 −0.0102～+0.0150。把这十个偏置**全部抹平**，RMSE 从 0.156010 最多到 0.155691，即 **−0.000319**（这是乐观上限，且只在测试集上测得，用于估算量级而非调参）。
- MLP 分支在链中权重 27.5%，折算到链上最多 **−8.6e-5**；其它分站专属分支已吸收部分偏置，实际预期 **≤5e-5**。
- 门槛是 −0.0002。**即使机制完全按预期工作，也过不了门。**

同一算法适用于其他表征类候选（one-hot→嵌入、加网络深度、换激活、加残差连接）：可解释的修正量级都小于链上权重 × 分站偏置上限。

## 要继续涨分，先决条件（都不在当前协议内）

1. **新信息源**：GEFCom2014 风电只有 u10/v10/u100/v100 四个 NWP 分量，已全部使用；温度、气压、机组布局、真实并网限电记录都没有。
2. **扩大训练数据**：把 2013 上半年并入拟合——用户明确否决。
3. **改评价口径**：如按提前量分段的 RMSE、按功率区间指标——不改变主指标。

在没有新数据的前提下，继续在同一组特征上换模型/换表征，期望收益低于判定噪声，属于钓鱼。
