## 已验证：天气邻域 + 时间顺序 OOF 跨站两层模型（整体方案）

- 同样 42,432 个测试小时，冻结 C 的 RMSE 0.170454204 → 0.162180238（降低 4.8541%），MAE 0.123454374 → 0.115982666（降低 6.0522%）。十站中八站 RMSE 降低，Zone 2、8 上升。
- 方法：24 小时预报日内的风能邻域、跨站第一层预测、第二层 LightGBM；第一层时间顺序 OOF 保证第二层训练输入不读取该时段标签。
- 2026-11-14 重新下载成功工作流的指标，并由逐站样本数加权平方误差重算合并 RMSE，与 summary.json 一致至 1e-12。
- [运行证据](https://github.com/Sunhuahai/wind-power-forecasting/actions/runs/42624048464)，下载 artifact 名 `kpower-replay-results`；详细逐站结果见 [[kpower-reproduction-results]]。
- 边界：这是整体方案效果，尚不能归因于单独的邻域或跨站特征；不是冠军源码或原比赛分数。已有测试集已用于报告，后续结果应标为同一历史基准上的探索性评价，不能当作全新盲测。

## 已验证：物理残差降低 MAE

十站 MAE 0.123454 → 0.121856，RMSE 0.170454 → 0.170535。适合作为 MAE 导向候选；不能宣称改善 RMSE。物理直接注入 RMSE 的微小差异置信区间跨零。见 [实验协议与报告](physics-experiment.md)。

## 已验证：相同样本的特征消融

新增 `--feature-set C|neighbors|full`。三组第二层都使用相同 OOF 时间段、相同超参数和验证早停；C 组也仅用该时间段，因此必须与这里的新 C 对照比较，不能把旧全年训练 C 当作唯一消融对照。第一层计算仍保留，以固定样本交集。

```sh
uv run python -m windpower.models.kpower_reproduction --sites all --feature-set C --experiment-id ablation_C_v1
uv run python -m windpower.models.kpower_reproduction --sites all --feature-set neighbors --experiment-id ablation_neighbors_v1
uv run python -m windpower.models.kpower_reproduction --sites all --feature-set full --experiment-id ablation_full_v1
```

已恢复 PostgreSQL 和十站数据，执行三组训练。区间覆盖率 73.19% 是另一个待解决问题，校准需要从拟合/早停中隔离出的校准时段。

2026-11-14 已恢复独立临时环境和十站官方数据，本轮使用 PostgreSQL **18.7**、LightGBM **4.7.0**（旧报告为各自历史环境）。批量实验标识 `ablation_20261114_v1`；环境详情保存在 `artifacts/kpower_ablation/ablation_20261114_v1/environment.json`。运行命令：

```sh
python scripts/run_kpower_ablation.py --experiment-id ablation_20261114_v1
```

十站 42,432 个相同测试小时结果：

|方案|MAE|RMSE|
|---|---:|---:|
|C（OOF 同时间段训练对照）|0.124524877|0.171821377|
|C + 天气邻域|0.119839461|0.167073932|
|完整两层（再加跨站预测）|0.115982666|0.162180238|

天气邻域相对 C 的 RMSE 差为 -0.004747446，七日块配对 95% 区间 [-0.006269744, -0.003219281]；完整两层相对邻域的差为 -0.004893694，区间 [-0.006190094, -0.003657589]。训练样本键和测试标签逐行完全一致。支持这两组特征在当前配对设计下有贡献，不能推断其他年份或任意学习器上的普遍收益。完整模型重跑指标与之前远端结果一致。

## 已验证的新 trick：验证集全站共享凸融合

固定候选为以上 C、neighbors、full 三组预测，仅最小化合并验证 MSE；全站共享三个非负权重，和为一。权重文件写入后才加载测试预测，禁止测试集选择权重。验证集已用于各基模型早停，故不能把该验证误差视为独立泛化误差。测试评价仍为探索性的历史基准。

```sh
python scripts/run_validation_blend.py --ablation-id ablation_20261114_v1
```

2026-11-14 已完成：43,008 个验证小时拟合出的权重为 **C 0.122281198、neighbors 0.084286243、full 0.793432559**。权重先写入文件，然后加载测试集。

|方案|测试 MAE|测试 RMSE|
|---|---:|---:|
|完整两层|0.115982666|0.162180238|
|验证集凸融合|0.115904742|**0.161552864**|

相对完整两层 RMSE 再降低 **0.3868%**；相对最初冻结 C 降低约 **5.22%**。融合−完整两层 RMSE 差 -0.000627374，2000 次七日连续日历块配对 95% 区间 **[-0.000963197, -0.000286049]**。MAE 差 -0.000077924，区间 [-0.000326755, 0.000176262]，尚不能声称 MAE 稳定改善。

实用要点：保留有差异但单独较弱的模型，使用验证集确定凸融合权重，可能降低最强单模型的误差；本次只试这个预先固定的全站共享方案，未按测试集搜索权重。区间仅反映固定模型在当前历史测试期的日块不确定性，不包括重新训练和新年份。

## 未通过：验证集选择的 MLP 结构小网格

严格协议（只用 2012 训练）下，在验证集上比较 6 个 MLP 结构：(128,64)/0.1、(256,128)/0.1、(256,128)/1.0、(384,192)/0.03、(128,64,32)/0.1、(64,32)/0.01。全部提前停止用训练期内留出，融合权重只用验证集。

验证 MSE 最优为 (128,64,32)/0.1（0.0211401，原结构 (128,64)/0.1 为 0.0212540），融合权重 0.1855。但同样 42,432 个测试小时上 RMSE 0.156740139 → 0.156399390（−0.22%），七日块配对 95% 区间 **[-0.000717, +0.000028]** 跨零，MAE 还上升 0.000313。**不登记为节点。**

证据：`artifacts/kpower_ablation/ablation_20261114_v1/mlp_tuned_v1/`（grid.json 含每个结构的验证 MSE 与融合权重）。可复用要点：结构网格能改善验证集，但幅度不足以跨过日块噪声；同一验证集既选结构又选权重会放大乐观偏差。

## 未通过：共享 LightGBM 的行列子采样 + 5 种子平均

严格协议下，对 26% 权重的跨站共享模型做方差治理：bagging_fraction=0.8、feature_fraction=0.8、5 个种子（42/7/2024/101/31337）平均，轮数冻结为原早停选出的 709 轮，分支系数 0.261716 冻结。

结果反而是 0.156009848 → 0.156090572（+0.0000807），七日块区间 **[-0.0000258, +0.0002321]**，跨零且方向为负。**不登记。**

证据：`artifacts/kpower_ablation/ablation_20261114_v1/shared_bagged_v1/`。可复用要点：多随机种子平均的收益来自高方差学习器（MLP 的初始化），而 LightGBM 在 65,760 行上本身稳定，子采样只是丢掉数据；方差治理不该当作通用技巧。

## 未通过：两段式（静风门槛）共享模型

诊断显示测试小时里 8.7% 的实际功率 <0.005（其中 2,813 个小时精确为 0），低功率段误差占 MSE 的 22.9%。因此把 26% 权重的共享分支换成两段式：LightGBM 二分类判断“是否接近静风”（阈值 0.005），另一个 LightGBM 只在非静风样本上回归，条件均值按 `P(发电)·E[Y|发电] + P(静风)·mean(静风样本)` 组合，两段都用验证集早停。

测试 RMSE 0.156009848 → 0.156201079（+0.000191），七日块区间 **[-0.0000183, +0.00070]** 跨零。**不登记。**

证据：`artifacts/kpower_ablation/ablation_20261114_v1/hurdle_shared_v1/`。可复用要点：RMSE 的最优点仍是条件均值，把点质量拆开估计并不会自动降低平方误差——单棵 L2 树已经把边界信息学到了。

## 未通过：MLP 分支的架构多样性平均

在已选结构 `(128,64,32)` 的 3 种子之外，再混入 3 个 `(128,64)` 种子共 7 个成员取均值，融合权重仍只用验证集拟合。

测试 RMSE 0.156009848 → 0.155936786（−0.047%），七日块区间 **[-0.000308, +0.000190]** 跨零；MAE 反而稳定改善（−0.000255，区间不含零）。**RMSE 未达标准，不登记。**

证据：`artifacts/kpower_ablation/ablation_20261114_v1/mlp_mixed_ensemble_v1/`。可复用要点：同结构多种子已经是主要收益来源，换架构混入只带来极小增量；该分支的信息量已被榨干。

## 未通过：十站合并的基础两层分支

把 8.8% 权重的“full”二级模型从分站训练改成十站合并（65,760 行 + farm 类别 + 31 叶），试图复刻第 5 节点池化 −1.68% 的效果，冻结分支系数 0.08778。

测试 RMSE 0.156009848 → 0.156017671（+0.0000078），七日块区间 **[-0.000184, +0.000170]**，MAE 还升 0.000144。**不登记。**

证据：`artifacts/kpower_ablation/ablation_20261114_v1/pooled_base_v1/`。可复用要点：池化的信息已经被后面的共享模型（26%）和时变分支吃掉，同一个特征集再池化一次是冗余的；早期池化有效是因为那时链里还没有共享组件。

## 设计越界：验证集训练的 meta-learner（未按协议执行，不计为实验）

曾想用 LightGBM 把各组件预测 + 工况特征（提前量、场站、小时、风速、跨站风速离散度）映射到最终功率，以替代固定凸组合。脚本把该模型直接拟合在 2013 上半年验证集上：先在验证集内部做 5 折时间块 CV 选轮数，再在全部验证行上重拟合，protocol 里也自述 "Meta-learner training set is the 2013 H1 validation"。

这等于把验证期标签用于训练一个模型，超出"验证集只用于早停、选结构与拟合融合权重"的边界，与已作废的三个重拟合节点同类。运行在数据准备阶段因列名不匹配报错中止，**没有产生任何指标、没有登记、没有进图、没有提交**；空目录已删除，脚本 `scripts/run_meta_learner.py` 保持未跟踪。

合法替代（需先确认）：用 2012 训练期内部的时间顺序 OOF 预测作为 meta-learner 的训练输入，验证集只做早停与健全性检查，测试集最后只评一次。注意 2012 OOF 预测本身来自训练期，不存在标签泄漏，但 meta-learner 的容量必须由验证集之外的信号约束，否则仍会在这个 43,008 行的样本上过拟合。
