## 约定

- **GEFCom2014（归档）**：数据划分固定为训练 2012、验证 2013 上半年、测试 2013 下半年；代码与旧表保留，可复现但不作为主线。
- **F01（主线）**：划分见 [评价协议](研究记录/f01-evaluation-protocol.md)——训练 2023-12-11～2024-09-01，验证 2024-09-01～2024-11-01，测试 2024-11-01～2024-12-12；测试集已于 2026-11-22 一次性评分，之后不得再用它做任何选择。
- 训练只用训练段；验证段只用于模型选择、早停与权重融合；测试段只在验证门禁通过后打开。
- 单机数据不输出广西政策准确率，相关字段保持 `null` 并写明原因。
- 只有 RMSE 前进且七日块配对区间上界 < 0 才登记；开测试集还需验证集区间上界 ≤ −0.0002。
- 失败方案只进 tricks，不进进展图。
- 周进展按 ISO 周归档；先在仓库 `docs/` 中完成并提交，再按项目约定同步到仓库外的 Obsidian 研究库。
