## 约定

- GEFCom2014 数据划分固定：训练 2012，验证 2013 上半年（只做选择/早停/权重），测试 2013 下半年（只评分）。
- F01 真实单机数据另立划分（`configs/f01_experiment.json`）：训练 2023-12-11～2024-09-01，验证 2024-09-01～2024-11-01，测试 2024-11-01～2024-12-12（首轮未打开；门禁见基线报告）。单机数据不输出广西政策准确率，字段为 `null`。
- 只有 RMSE 前进且七日块配对区间上界 < 0 才登记；开测试集还需验证集区间上界 ≤ −0.0002。
- 失败方案只进 tricks，不进进展图。
- 周进展按 ISO 周归档；先在仓库 `docs/` 中完成并提交，再按项目约定同步到仓库外的 Obsidian 研究库。
