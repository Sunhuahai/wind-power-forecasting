# 真实数据项目架构总览（F01 · 数据库到模型训练）

> 本文是**当前主线**（真实数据）的完整技术底稿，覆盖数据库结构、数据流、特征、模型训练、评价与部署。
> 历史线（GEFCom2014 公开数据）已于 2026-11-23 经用户决定**冻结**，仅作历史参考，不再投入；其代码与实验记录原样保留，不影响本主线。
> 相关：[F01 数据审计](../研究记录/f01-data-audit.md) · [首轮基线报告](../研究记录/f01-baseline-first-round.md) · [数据库契约](guangxi-operational-storage.md) · [实施规划](02_F01十分钟SCADA数据驱动的项目结构与评价体系规划.md)。

## 一页结论

```
原始 CSV（GB18030，sha256 锁定，不入公开仓库）
   │  ①审计（只读，规则预注册）
   ▼
PostgreSQL 18.6 + TimescaleDB 2.32.1
   │  ②入库（原始行不可变 + 规范行 + 质量标记，幂等）
   ▼
as-of 样本构造（发布时刻 T 只用 ≤T−10min 记录）
   │  ③严格防泄漏
   ▼
四个基线模型（持续 / 季节 / Ridge / LightGBM）× 24 个提前量（10—240 分钟）
   │  ④训练集拟合，验证集选型，测试集一次性评分
   ▼
统一评价（MAE/RMSE/Bias/分组/爬坡/覆盖/耗时）
   │
   ├─→ artifacts/f01/ 证据五件套（summary / per_lead / per_day / quality_report / report）
   └─→ 腾讯云仪表盘（纯结果视图，basic_auth）
```

核心结果（测试集 2024-11-01～12-12，一次性评分）：最优 LightGBM **RMSE 877.2 kW**，较持续法（1105.4）低 **20.5%**；爬坡方向准确率 77.9%；政策准确率 `null`（单机数据无资格）。

## 2. 数据库架构

### 2.1 选型与运行

- **PostgreSQL 18.6 + TimescaleDB 2.32.1**（钉版镜像 `docker/db-timescale.Dockerfile`：基础镜像 `postgres:18.6` + `postgresql-18=18.6-1.pgdg13+2` + `timescaledb-2-postgresql-18=2.32.1~debian13-1806` 及其 loader 包，三包全钉死）。
- Omarchy 开发库：Docker Compose，端口 `127.0.0.1:55432`，数据卷持久化；安装前 `pg_dump -Fc` 备份（20 MB，`backups/` 不入库）。
- `shared_preload_libraries=timescaledb`；Alembic 迁移至 **0004**；24 张表、**5 张 hypertable**。
- 运维原则：动数据先备份、激活脚本独立执行、不启用自动清理/压缩。

### 2.2 三层表结构（业务语义隔离）

**第一层：GEFCom2014 实验层（0001–0002，已冻结）**
`wind_farms`、`power_observations`（175,440 行）、`nwp_forecasts`、`dataset_splits`、`model_runs`、`predictions`、`nwp_revisions`。
历史证据原样保留，不再扩展；以 2012/2013 划分的旧协议与本文主线无关。

**第二层：广西场站业务层（0003，空置待真实数据）**
| 表 | 类型 | 作用 |
|---|---|---|
| `farm_capacity_history` | 普通表 | 装机容量生效区间（政策分母依据） |
| `operational_power` | hypertable | 场站并网点 15 分钟 **MW** 实发/可用/理论功率，非负，含 `received_at` 迟到修订 |
| `operational_nwp` | hypertable | NWP 批次（起报/接收/有效时间 + 风矢量/温压） |
| `operational_events` | 普通表 | 限电/故障/检修/考核豁免（审批状态） |
| `forecast_issuances` / `forecast_values` | 普通表 / hypertable | 每次发布（日前 96 点、超短期 16 点）与逐点预测 |
| `dispatch_submissions` / `dispatch_receipts` | 普通表 | 报送报文哈希与调度回执（追加式） |
| `gx_policy_versions` | 普通表 | 已注册两版规则：正式版 60%/65%、草案 65%/75% |
| `gx_daily_evaluations` | 普通表 | 政策评分结果（追加式） |

**第三层：F01 单机 SCADA 层（0004，激活中）**
| 表 | 类型 | 行数 | 作用 |
|---|---|---:|---|
| `data_ingest_files` | 普通表 | 1 | 文件登记：sha256 自然键、编码、行列数、时间语义、导入版本 |
| `wind_turbines` | 普通表 | 1 | 风机资产：`external_id=F01`，`farm_id=NULL`（不虚构场站），`rated_power_kw=NULL`（型号字符串不构成容量证据） |
| `turbine_scada_raw_10m` | 普通表 | 52,749 | **不可变原始载荷** JSONB（全 54 列原字符串，含 `--` 与哨兵值） |
| `turbine_scada_10m` | **hypertable**（13 个 30 天 chunk） | 52,749 | 规范化分析行：功率 **kW 允许负值**、风况/机械/状态列 + `quality_flags` + 原始行引用 |
| `turbine_power_15m_proxy` | hypertable | 0 | 15 分钟研究性代理（**语义确认前禁写**，转换函数与合成测试已就绪） |
| `feature_snapshot_manifest` | 普通表 | 3 | 每次训练运行的输入快照登记（数据版本、可见性假设、特征清单） |

### 2.3 设计约束（为什么这样建）

1. **单机 ≠ 场站**：kW 单机表与 MW 场站表物理分离；负功率只允许存在于单机表（场站表 CHECK 非负）；`farm_id` 允许为空，不虚构归属。
2. **版本可追溯**：文件 sha256 为自然键；`(turbine_id, observed_at, file_id)` 主键支持多版本追加，查询按导入时间做 as-of 选择；重复导入幂等（原始行 DO NOTHING、规范行重推导），实测两次导入行数不变。
3. **hypertable 就绪**：高频表主键均含时间列；外键方向为 hypertable→普通表；激活后范围查询触发 chunk 裁剪（月度查询实测只扫 2 个 chunk）。
4. **时间语义显式化**：源 naive 时间保持 naive + 文件级 `time_semantics` 记录；场站层一律 `TIMESTAMPTZ`（绝对时刻），业务日按 `Asia/Shanghai` 换算。
5. **单位显式**：字段名带单位（`_kw`、`_mw`、`_deg`、`_h`），杜绝静默换算。

## 3. 数据处理流程

### 3.1 导入（`windpower.data.scada_f01`）

1. `read_raw`：校验 SHA-256 与 52,749×54 规模 → GB18030 全列字符串读取（`--` 原样保留）。
2. `typed_rows`：逐行解析规范字段 + 逐行质量标记（`quality_flags` JSONB）。
3. 入库：`data_ingest_files` 登记 → `wind_turbines` 资产 → `turbine_scada_raw_10m`（500 行/批，ON CONFLICT DO NOTHING）→ `turbine_scada_10m`（ON CONFLICT DO UPDATE 重推导标记）。
4. 审计报告：`artifacts/f01/quality_report.json` + 控制台摘要；`verify_counts()` 核对行数、负值数、哨兵数。

### 3.2 质量规则（预注册，只标记不删改）

| 标记 | 规则 | 处理 |
|---|---|---|
| `negative_grid_power` | 网侧功率 <0 | 原值保留（真实净取用），不截零 |
| `zero_grid_power` | =0 | 不视为缺失 |
| `sentinel_847_intake_temp1/2` | =847 | 整列排除出特征，不当温度 |
| `yaw_ring_temp_anomaly` | >200℃ | 通道整体不纳入特征 |
| `pitch_outside_canonical` | 任一叶片 ∉ [−10,100]° | 特征掩码（该行桨距置缺失） |
| `yaw_position_outside_canonical` | \|偏航\| >360° | 原值保留，语义确认前不取模 |
| `state_duration_exceeds_step` | 任一状态时长 >1/6 h | 只记录（可能汇总缺口） |
| `after_time_gap` | 相邻记录差 ≠10 分钟 | 样本构造按 24h 完整性要求剔除 |

### 3.3 样本构造（`windpower.features.scada_samples`）

- **可见性假设**（预注册 `OFFLINE_REPLAY_COMPLETED_INTERVAL`）：`统计时间=t` 视为区间 `[t,t+10min)` 平均，t+10 分钟才完整可见；发布时刻 T 只允许 `observed_at ≤ T−10min` 的记录。该规则在区间起点/终点两种未确认语义下均无泄漏。
- **每个样本**：`(发布时刻 T, 目标时刻 T+10k)`，k=1..24；标签为网侧功率 kW。
- **有效性**：前 24 小时 144 格功率记录完整 + 41 维特征全部有限 + 24 个目标标签齐全，否则整次发布剔除。
- **覆盖率**：候选发布 52,680 → 有效 42,896（81.4%）；剔除原因：历史不完整 8,466（99 个缺失网格点所放大）、特征掩码 26、标签不完整 1,292（数据末尾）。
- **特征（41 维）**：功率 lag 1/2/3/6/12/36/72/144 步与 24h 窗口统计（均/标准差/最值）、近段变化量；风速 lag 1/6/144 + 窗口统计；环境温度 lag 1/144；叶轮/发电机转速；桨距均值；六列状态时长；小时/星期/年积日 sin-cos；提前量 `lead_step`。
- **划分**（按目标时间左闭右开）：训练 2023-12-11～2024-09-01（31,178 发布 / 747,996 行）、验证 2024-09-01～2024-11-01（7,178 / 171,720）、测试 2024-11-01～2024-12-12（4,586 / 109,788，一次性使用）。同一目标标签只归属一段；发布可跨段但特征只来自其可见历史。

## 4. 模型与训练

### 4.1 四个模型（`windpower.models.scada_train`）

| 模型 | 机制 | 关键参数 | 训练成本 |
|---|---|---|---|
| Persistence | 最后一格可见功率（lag1）保持 4 小时 | 无 | 0 |
| Seasonal | 目标时刻过去 7 天同时刻均值，全缺回退 lag1 | 7 天 | 0 |
| Ridge | StandardScaler + Ridge，41 特征 + lead | alpha=100（验证集从 {0.1,1,10,100} 选） | 秒级 |
| LightGBM | 梯度提升树，同特征 | 600 树 / lr 0.05 / 31 叶 / 早停 50 轮（第 82 轮停） | ~2 s（16 核） |

**预测不裁剪**：负功率是真实状态，截零会美化停机时段误差。

### 4.2 训练与选择协议（`configs/f01_experiment.json` 预注册）

1. 训练集拟合参数；验证集用于 **Ridge alpha 选择、LightGBM 早停、门禁判定**；
2. 门禁 `F01_FIRST_ROUND_VALIDATION_GATE`：①pooled RMSE 优于持续法 ②逐提前量均值优于持续法 ③防泄漏/协议测试全绿 —— 已通过（3/3）；
3. 测试集**一次性**评分（2026-11-22 用户授权）：加载冻结模型 bundle，阈值原样复用，评分前先用验证集干跑复现已存指标（Ridge 911.5467 / LGBM 929.3906）证明代码无误；
4. 测试结果不用于任何后续选择/调参。

### 4.3 结果（kW，同一有效样本配对比较）

| 模型 | 验证 MAE/RMSE | 测试 MAE/RMSE |
|---|---|---|
| Persistence | 686.7 / 1032.3 | 754.4 / 1105.4 |
| Seasonal | 1171.6 / 1523.6 | 1039.9 / 1342.2 |
| Ridge | **667.7 / 911.5** | 707.4 / 933.3 |
| LightGBM | 678.8 / 929.4 | **659.4 / 877.2** |

- 分提前量：≤40 分钟持续法最优；约 50 分钟起学习模型反超；240 分钟 1124（LGBM）/1139（Ridge）对 1360（持续法）。
- 分组（Ridge，验证）：风速 <3 m/s MAE 376 → 9–12 m/s 1053；高功率区间误差最大（2089）。
- 爬坡（训练期 \|ΔP30\| 95 分位 = 1,267 kW）：测试期 5,952 个事件，LightGBM 事件内 MAE 1,145 kW，方向准确率 77.9%。
- **验证期冠军 Ridge、测试期冠军 LightGBM**——排序翻转已如实记录，不做二次选择。

## 5. 评价与输出

- **指标**：MAE/RMSE/Bias、逐提前量、逐日、风速/状态/功率分组、爬坡（事件阈值预注册）、覆盖率、训练/推理耗时；所有模型同一有效样本集合。
- **证据五件套**：`artifacts/f01/{summary,test_summary}.json`、`per_lead.csv`、`per_day.csv`、`quality_report.json`、`report.md`（+`run_manifest`/`test_manifest`，含配置哈希与授权记录）。
- **政策资格控制**：单机数据 → `GX_policy_accuracy = null` + 原因；评分器 `guangxi.py` 按正式文件实现（60%/65%、容量下限分母、16 版均值、草案单列），14 项合成单测通过，等场站数据启用。
- **可视化**：`scripts/build_dashboard.py` 生成单文件零依赖 HTML（内联 SVG、聚合指标、无原始行）；部署于腾讯云 Caddy `http://49.233.91.122/windpower/`（basic_auth、`no-cache`、非侵入配置）。
