# 2026-W47 本周进展概览

**统计截至：2026 年 11 月 22 日。**本周完成从"政策研究 + 规划"到"真实数据闭环"的跨越：F01 单机十分钟 SCADA 完成审计、入库、建模、验证、一次性测试评分与可视化上线。周次按 ISO 周划分。

**方向决定（11-23）：** GEFCom2014 公开数据线冻结为历史参考，不再投入；项目主线为真实数据（当前 F01，未来广西场站）。

## 一、本周完成的工作

### 1. 政策与规划文档（11-21 已提交）

- 更新[《广西风电功率预测考核政策与训练评估适配》](01_广西风电功率预测考核政策与训练评估适配.md)：在政策与公式研究基础上，增加 100 MW 场站端到端示例。
- 新增[《F01 十分钟 SCADA 数据驱动的项目结构与评价体系规划》](02_F01十分钟SCADA数据驱动的项目结构与评价体系规划.md)（本次实施任务书，含 T00—T09 任务卡）与[《广西风电场生产数据库结构与数据契约》](../../部署与工程/guangxi-operational-storage.md)。
- 政策评分器（`guangxi.py`）按正式文件实现（日前 60%、超短期 65%、分母 max(参考功率, 20%容量)、16 版均值），14 项合成单测通过；草案 65%/75% 单列。

### 2. F01 真实数据闭环（T00—T04，Omarchy 实测）

- **审计与入库**：52,749 行 × 54 列全部复核（缺 99 网格点、负功率 9,968 条原值保留、847 哨兵 50,084、最大缺口 180 分钟）；预注册质量规则只标记不删改；Alembic 0004 六表入库，重复导入幂等。
- **建模**：严格 as-of 样本（发布时刻 T 只用 `≤T−10min` 记录，防泄漏逐位验证）；四模型 × 24 个提前量（10—240 分钟），全部报基础指标、分组、爬坡、覆盖率和推理耗时。
- **严格协议**：训练拟合 → 验证选型（alpha/早停/门禁）→ 测试**一次性**评分（11-22 经用户授权，冻结模型与阈值）。验证期 Ridge 最优 **RMSE 911.5 kW**；测试期 LightGBM 最优 **877.2 kW**，较持续法（1105.4）低 **20.5%**。验证期排序未延续到测试期，已如实记录、不二次选择。
- 报告：[数据审计](../../研究记录/f01-data-audit.md) · [首轮基线（含测试评分）](../../研究记录/f01-baseline-first-round.md)；机器可读证据在 `artifacts/f01/`。

### 3. 数据库：TimescaleDB 安装与激活（11-21）

- 生产目标 `PostgreSQL 18.6 + TimescaleDB 2.32.1` 在 Omarchy 开发库落地：钉版 Docker 镜像、备份先行（20 MB `pg_dump`）、五张高频表转 hypertable（单机表 52,749 行 → 13 个 chunk）、迁移后数据零损失、chunk 裁剪与幂等导入实测通过。
- 实测修正了激活脚本的 `by_range` 签名缺陷（脚本首次真正执行时暴露）。

### 4. 可视化上线（11-21～22）

- 单文件零依赖仪表盘部署至腾讯云 Caddy：`http://49.233.91.122/windpower/`（basic_auth，TCP:80 已放行，公网 200 验证）；展示验证/测试指标、分提前量/逐日误差、分组诊断、功率包络与审计信息。见[部署说明](../../部署与工程/f01-dashboard-deployment.md)。
- 修复折线图在全浏览器不可见的颜色键名 bug（经用户反馈与截图代读定位，已回归验证）。

### 5. 工程保障

- **108 项测试全绿**（含数据库集成），覆盖编码解析、幂等导入、时间缺口、异常值保留、防泄漏、划分边界、政策 null 资格等 10 类场景。
- 修复 3 个真实缺陷：lead 与目标时间 off-by-one、10→15 分钟跨界权重、图表折线颜色键名。
- 全部代码与证据已提交并推送 GitHub（最新 `d3fb8bd`）。

## 二、主要结论

| 事项 | 结论 |
|---|---|
| 已核实正式规则 | 日前准确率门槛 60%，超短期 65%；归一化分母 = max(参考功率, 20% 当月装机容量)；超短期对同一目标 16 版先平均 |
| 2026 年草案 | 拟 65%/75%，误差聚合顺序变化；未确认生效，单列不混算 |
| F01 数据事实 | 单机 10 分钟，52,749 行；负功率 18.9% 为真实净取用，保留不截零；源时区与区间语义未确认 |
| F01 验证期 | Ridge RMSE 911.5 kW（持续法 1032.3）；门禁 3 项全过 |
| F01 测试期（一次性） | LightGBM RMSE 877.2 kW（持续法 1105.4）；爬坡方向准确率 77.9% |
| 政策评价资格 | 单机数据 ≠ 场站并网点参考曲线：`GX_policy_accuracy = null`，无正式分数 |
| 部署边界 | 无历史 NWP，不宣称可部署 D+1；无真实接收时间，不宣称生产实时能力 |

## 三、后续重点

1. **确认源数据语义**：`统计时间` 的时区与区间起止定义 → 解锁 15 分钟研究性代理标签（转换函数与合成测试已就绪，真实标签当前阻塞）。
2. **获取历史 NWP 批次**（起报 + 实际接收时间）→ 才能开展可回放的 D+1 模型。
3. **接入场站并网点 15 分钟真值 + 装机容量 + 限电/可用功率记录** → 启用广西政策准确率研究性回放（业务表与评分器已就绪，等数据填入）。
4. 调度报送格式与回执 → 上报率评价与结算对账（T08/T09）。
