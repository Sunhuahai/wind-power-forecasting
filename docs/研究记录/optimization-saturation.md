# 优化饱和评估与已封路线清单

更新：2026-11-16。严格协议：训练只用 2012，验证集只做早停/选结构/定权重，测试集只评分。
当前最优：**0.156009848**（9 个成功节点，相对原 C 基线 0.170454204 降低 **8.47%**）。测试集累计使用 11 次。

## 一、结论

这条链在现有信息源上**已饱和**，证据有两条：

1. **最近四轮的效应量都在 1e-4 量级或更低，且没有一轮成立**：

| 轮次 | 效应量 | 判定 |
|---|---:|---|
| MLP 种子 3→8 | 验证 ΔRMSE −0.000266 | 区间 [−0.000551, +0.000028] 跨零，未过 −0.0002 门槛 |
| 滚动 OOF 残差特征 | 验证 −0.000138 | 区间跨零；打乱顺序对照仅差 2.7e-6，无时间信息 |
| 提前量分段建模 | 验证 −0.000444 / 测试 −0.000013 | 测试区间 [−0.000457, +0.000464] 跨零，不成立 |
| 跨站一致性特征 | 验证 −0.000074 | 区间 [−0.000215, +0.000064] 跨零，门禁未过 |

2. **余量测算**：把现行最优在测试集上的十个分站偏差（−0.0102～+0.0150）**全部抹平**，RMSE 最多从 0.156010 到 0.155691，即 **−0.000319**；MLP 分支在链中权重 27.5%，折算到链上 ≤ **−8.6e-5**，其它分站专属分支已吸收部分偏置，实际预期 **≤5e-5**。而开测试集的门槛是 −0.0002 —— **即使机制完全按预期工作也过不了门**。

同一算术适用于所有"换表征/换超参"的候选（one-hot→嵌入、加深度、换激活、加残差连接）：可解释的修正量级都小于「链上权重 × 分站偏置上限」。

## 四、机制不成立：meta-learner

曾想用 LightGBM 把各组件预测 + 工况特征映射到最终功率。

- **设计层面**：原脚本直接在 2013 上半年验证集上训练（5 折选轮数后全量重拟合），属于"验证集标签进训练"，越界，已中止，未产生任何指标。
- **机制层面**：改为合法的 2012 期内 OOF 后做可行性检查（3 折、65,760 行、固定轮数、不碰验证/测试），固定凸融合 0.155390 vs meta 0.162994，**三折全负、合并 +4.9%**。
- 结论：**机制不成立**，不是"试过没用"；不要再回头。

## 五、链为什么饱和：三类证据

1. **信息面已用尽**：GEFCom2014 风电只有 U10/V10/U100/V100 四个 NWP 分量，全部已用；温度、气压、机组布局、限电记录都没有。十个 ZONEID 是匿名站，外部再分析数据无法对位接入。
2. **收益递减曲线**：节点 1（跨站两层）−4.85%，节点 5（共享模型）−1.68%，之后每一步都 ≤0.58%，最近四轮 ≤0.03%。
3. **噪声地板**：七日块配对区间的半宽约 2e-4；低于这个量级的改动，即使方向为正也无法被证明。

## 六、要继续涨分，先决条件（都不在当前协议内）

1. **新信息源**：限电/弃风标记、可用容量、检修记录（价值最高）；或温度/气压（空气密度）、轮毂高度/布局（尾流）。
2. **扩大训练数据**：把 2013 上半年并入拟合——用户明确否决。
3. **改评价口径**：按提前量分段、按功率区间指标——不改变主指标。
