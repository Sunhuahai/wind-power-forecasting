## 与此前审计结论的核对

- 规划文档 §1.1 各数字（52,749 行、99 缺点、负功率 18.90%、哨兵 50,084、四列全缺失等）**全部复核通过**。
- "最大连续时间差 3 小时"**属实**：即 2024-05-27 的 180 分钟缺口（首次快速勘察曾误读为 120 分钟，因只查看了差值分布前 5 行；以 `quality_report.json` 为准）。
- 时间格式为 `2023/12/11 00:00`（斜杠），此前未明确记录。

## 时间语义（未确认，不擅自认定）

- `统计时间` 无时区，且**没有区间起点/终点说明**：可能是 [t, t+10min) 平均或 [t−10min, t) 平均。
- 本轮所有特征构造采用保守规则：发布时刻 T 只使用 `observed_at ≤ T−10min` 的记录
  （`OFFLINE_REPLAY_COMPLETED_INTERVAL`，见 `configs/f01_experiment.json`）。
  该规则在两种区间语义下都无未来信息泄漏，代价是特征最多延迟 10 分钟。
- 原文件无数据接收时间，不能证明历史观测在某次模拟发布时已可见；离线回放假设已显式登记，
  **不得宣称为已验证的生产实时能力**。

## 处理原则的落实

| 原则 | 落实 |
|---|---|
| 不覆盖原始文件 | 只读；`data/raw/f01/` 已被 `.gitignore` 排除，不上传公开 GitHub |
| 负功率不截零 | 原值入库（`turbine_scada_10m.grid_active_power_kw` 允许负），行级 `negative_grid_power` 标记 |
| 异常温度不当真 | 进风口两列、偏航集电环温度不进第一轮特征；847 作为哨兵标记 |
| 保留处理原因 | 全部规则、单位、阈值在 `quality_scada.py` 与报告中可审计；26 条桨距越界行在特征构造时被掩码剔除（样本覆盖率影响见基线报告） |
| 单机 ≠ 场站 | F01 未虚构场站归属（`farm_id=NULL`），未写入场站 `operational_power`（MW、非负） |
| 重复导入幂等 | `file_id=sha256` 为自然键；实测重复导入两次行数不变（52,749/52,749/负值 9,968） |
