# 跨站预报风速时变与验证集融合

在原 C、邻域、跨站预测及30维原始风场特征上，追加每站风速 t±1、t±3 和 t+1−t−1 梯度，共50维。所有位移严格位于同一次24小时预报内，边界截断。仅预报字段，无目标功率。

相同训练样本和参数、验证早停。验证集最小化MSE后冻结融合权重：前一最优 0.544211283，新时变模型 0.455788717。
