# 多种子平均的标准化 MLP（结构由验证集选出）

严格协议：只用 2012 年 OOF 样本训练（65,760 行），验证集（2013 上半年，43,008 行）只用于选择、早停与融合权重，测试集（2013 下半年，42,432 小时）只评一次。

上一轮在验证集上比较 6 个结构，选出 `(128,64,32)`、`alpha=0.1`，但单模型测试 RMSE 0.156740139 → 0.156399390（−0.22%），七日块区间 [-0.000717, +0.000028] 跨零，未通过。本轮只改一件事：同一结构用 3 个随机种子（42 / 7 / 2024，提前停止各用训练期内 15% 留出）训练后取预测均值，融合权重仍只用验证集拟合。

|方案|MAE|RMSE|小时|
|---|---:|---:|---:|
|baseline（第 7 节点 mlp_blend）|0.111645608|0.156740139|42432|
|mlp_seedavg（单分支）|0.118526161|0.167325567|42432|
|mlp_seedavg_blend|0.111269185|**0.156009848**|42432|

融合权重 **0.725116 / 0.274884**（基线 / 种子平均 MLP），验证 MSE 0.0210285（单结构单种子为 0.0211401）。RMSE 差 **-0.000730290**，七日块配对 95% 区间 **[-0.001251885, -0.000228719]**，不含零；MAE 差 -0.000376423，区间 [-0.000831237, +0.000096002]，跨零，不声称 MAE 改善。三个种子的迭代轮数为 122 / 92 / 114。

2000 次七日连续日历块 bootstrap，同日所有站点共同重采样。验证集同时用于结构选择与融合权重，存在乐观偏差；这是同一历史测试集上的探索性评价，NWP 与观测实际到达时间未知，区间不涵盖重训或新年份不确定性。
